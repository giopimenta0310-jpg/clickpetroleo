# CPG — Gerador de Criativos

Gerador de Feed (1080×1350) e Stories (1080×1920) para Click Petróleo e Gás.

## Uso local

```bash
npm start
```

Abra `http://localhost:3000` e mantenha o terminal aberto durante o uso.

## Publicação na Vercel

Importe este repositório na Vercel e faça o deploy sem comandos de build. As funções em `api/` extraem título e imagem Open Graph das matérias e viabilizam a exportação dos criativos.
